# Historical research and prototype

`research/` contains the original notebooks and data exploration previously stored under `PrithviHL/`. `prototype/` contains the original final Streamlit submission, deployment examples, reports, sample data, and trained-model artifacts previously stored under `final_submission/`.

These files are retained as historical reference. Their internal relative paths, environment requirements, deployment instructions, and performance claims may be outdated. They are not used by the current web app, CI, or live trip planner. Some original source copies were changed only to remove an embedded credential; the old Python app now reads `RTS_API_KEY` from its environment.

The supported application and current instructions are documented in the root README. Binary Python models are not executed by the current app.
